Features

🏔️ Terrain Analysis

  • Hillshade (configurable azimuth/altitude)
  • Slope (degrees, Horn's method)
  • Aspect (0–360°, north-referenced)
  • 3×3 gradient kernel (Horn's algorithm)
  • Nodata-aware processing

🧮 Map Algebra

  • Unary: add, multiply, sqrt, abs, log
  • Binary: add, subtract, multiply, divide
  • Binary: min, max (cell-by-cell)
  • Reclassification (range-based)
  • Dimension validation

📊 Raster Type

  • 2D grid (row-major f64)
  • Configurable cell size
  • Nodata sentinel handling
  • Random access get/set
  • Clone-on-write semantics

🖥️ CLI

  • Stats: elevation, slope, aspect at center
  • Hillshade: configurable sun angle
  • Synthetic DEM generation for testing

Quick Start

use terrano_core::{Raster, slope, hillshade};

let dem = Raster::from_vec(100, 100, elevation_data, 10.0, -9999.0).unwrap();
let slopes = slope(&dem);       // degrees
let hs = hillshade(&dem, 315.0, 45.0);  // sun from NW at 45°
